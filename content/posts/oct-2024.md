### Wiki Updates

- Did a complete overhaul of the **[Beginners Guide](https://gofmhy.tech/beginners-guide)**. Removed outdated links, added new sites, and rewrote all the tips.

- Reorganized the [Anime Streaming](https://gofmhy.tech/video#anime-streaming) section based on **[tournament results](https://challonge.com/Anime_Streaming.svg)**.

- Reorganized both [Multi / Single Hosts](https://ibb.co/X7SC3f8) in the [Streaming section](https://gofmhy.tech/video) as people felt they were somewhat outdated.

- Added a section for [Steam Deck](https://gofmhy.tech/gaming-tools#steam-deck) in Gaming Tools.

### Stars Added ⭐

- Starred [datadiff](https://gofmhy.tech/video#drives-directories) in Drives / Directories. Media directory with fast download speed, similar to vadapav / moo.

- Starred [Proton Pass](https://gofmhy.tech/internet-tools#password-managers) in Password Managers. Feature-rich manager comparable with things like Bitwarden.

- Starred [Miruro](https://gofmhy.tech/video#anime-streaming) in Anime Streaming. This was the winner of our anime streaming polls.

- Starred [RockMods](https://gofmhy.tech/mobile#modded-apks) in Modded APKs. RockMods label all their releases correctly and are usually one of the main sources of other groups.

- Starred [OpenStax](https://gofmhy.tech/reading#educational-books) in Educational Books. Well-organized educational textbook site.

- Starred [Yet Another Call Blocker](https://gofmhy.tech/mobile#number-sms) in Number / SMS. Hasn't been updated in a while, but it doesn't need to be as it's connected to a crowdsourced number [database](https://www.shouldianswer.com/).

- Starred [UrlCheck](https://gofmhy.tech/mobile#android-privacy) in Android Privacy. Customizable open-source URL cleaner for Android.

- Starred [Rev Wallpaper](https://gofmhy.tech/system-tools#wallpapers) in Wallpapers. Reverse wallpaper search engine.

- Starred [Edge-Remover](https://gofmhy.tech/internet-tools#browser-tools) in Browser Tools. Easy way to uninstall Microsoft Edge.

- Starred [Akuse](https://gofmhy.tech/video#anime-streaming) in Anime Streaming. Open-source anime app with a nice UI.

- Starred [Movies Countdown](https://gofmhy.tech/video#calendar-upcoming) in Calendar / Upcoming. Tracks upcoming movie releases, both digital and theater.

- Starred [Simple Tab Groups](https://gofmhy.tech/storage#tab-managers) in Tab Managers. Feature-rich tab manager with plugin support.

### Things Removed

- Removed Essential from Minecraft mods as they have a history of malicious practices and there are better options anyway.

- Removed Slider as they've been [shut down](https://ibb.co/NnY4M8b).

- Removed AnimeOut as they've closed signups. 

- Unstarred LookMovie as they've locked 720p [behind a paywall](https://ibb.co/9W50NTg).

- Unstarred Modyolo and LiteAPKs as both mislabel releases from other groups as their own and tag apps as newer versions than actually exist in order to get more downloads.

- Unstarred Gemini as many people consider it less useful than other AI.

- Unstarred Duolingo as there are better ways to learn languages.

- Unstarred Tixati as it's closed-source and there are better options like qBit, Transmission, and Deluge.
